## สิ่งที่ฝึกในสัปดาห์นี้

- HTML5 semantic elements (`<head>`, `<body>`, `<h1>`-`<h6>`, `<table>`, `<form>`, `<ul>`, `<ol>`)
- Inline CSS (`style` attribute) และ `<style>` tag
- HTML Forms: `input` types (text, password, email, radio, checkbox, submit button)
- การจัดวางเลย์เอาต์ด้วย CSS (`display: flex`, `text-align`)
- การใช้ Google Fonts
- JavaScript พื้นฐาน (`window.onload`, `alert`, `addEventListener`)  แอบนอกเรื่องฟังชั่นเดียว55555
- การใช้ `<audio>` tag
- การทำ internal linking ระหว่างหน้า
